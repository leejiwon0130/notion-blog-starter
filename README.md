# 수강생용 — 노션 연동 브랜딩 사이트 구축 지시서

> **이 파일을 Claude Code에 그대로 전달하세요.**
> 목적: 노션에 글을 쓰면 자동 발행되는 개인 브랜딩 사이트를 Netlify에 배포.
> 대상: 창원·경남 지역 마케팅 강사/소상공인 (비개발자)

## 0. 먼저 알아야 할 것 (기대치 조정)

**이 사이트가 하는 일과 못 하는 일을 정확히 알고 시작하세요.**

| 질문 | 답 |
|---|---|
| AI(GPT·제미나이)가 **읽을 수 있나?** | ✅ 된다. 정적 HTML이라 오히려 워드프레스보다 유리 |
| 구글에 **색인되나?** | ✅ 된다 |
| AI가 **나를 추천해주나?** | ⚠️ **사이트만으로는 안 된다** |

**근거 (2026년 조사)**
- GPTBot·ClaudeBot·PerplexityBot 등 **AI 크롤러는 JavaScript를 실행하지 않는다.** GPTBot 5억 건 분석에서 JS 실행 0건 → **HTML에 글자가 있어야 읽힌다**
- 지역 업체 AI 추천에서 **인용 출처의 약 77%가 사이트 밖**(리뷰·디렉터리·제3자 언급)
- ChatGPT 로컬 답변의 70% 이상이 Foursquare, 제미나이는 구글 기반
- **내 홈페이지는 "사실 확인용"**이지 추천의 출처가 아니다

**결론**: 홈페이지는 필요조건. 추천받으려면 **구글 비즈니스 프로필 + 네이버 플레이스/블로그**가 반드시 함께 있어야 한다. (9번 항목 참고)

## 1. 기술 스택 (확정)

```
Next.js 16 (App Router)  +  Notion API  +  Netlify
```

> ✅ **이 템플릿은 실제로 빌드 검증을 마쳤습니다.**
> `npm run build` 통과 · `sitemap.xml`·`robots.txt` 자동 생성 확인 · ISR 1시간 적용 확인

| 선택 | 이유 |
|---|---|
| **Next.js 16 App Router** | `generateMetadata`로 글마다 메타태그 자동 삽입, `sitemap.js`/`robots.js` 기본 지원 |
| **ISR (`revalidate = 3600`)** | 봇이 오면 **완성된 HTML**을 받음. 1시간마다 노션 자동 반영 |
| **notion-to-md + react-markdown** | 노션 본문을 `<h2> <p> <ul>` 같은 **시맨틱 HTML**로 렌더 |
| **JavaScript (TS 아님)** | 비개발자 수강생 진입장벽 낮춤 |

> `react-notion-x`는 쓰지 않는다 — CSS가 무겁고 커스텀이 어렵다.

## 2. 노션 준비 — 표는 자동으로 만들어집니다

**직접 표를 만들지 않아도 됩니다.** 아래 두 가지만 하면 나머지는 스크립트가 처리합니다.

### 1) 통합(API 키) 만들기
[notion.so/my-integrations](https://www.notion.so/my-integrations) → **새 API 통합** → **시크릿 키**(`ntn_...`) 복사

### 2) 빈 페이지 만들고 연결하기
노션에서 **빈 페이지**를 하나 만들고 → 우측 상단 `···` → **연결** → 만든 통합 선택 → **페이지 주소 복사**

### 3) 표 자동 생성
```bash
cp .env.example .env.local     # NOTION_TOKEN, NOTION_PARENT_PAGE_ID 입력
npm run setup:notion
```

이렇게 생성됩니다.

| 속성 | 종류 | 용도 |
|---|---|---|
| 제목 | 제목 | 글 제목 |
| 슬러그 | 텍스트 | 글 주소 |
| 요약 | 텍스트 | 검색 결과 설명문 |
| 카테고리 | 선택 | 태그 |
| 발행일 | 날짜 | 정렬 |
| **발행** | 체크박스 | **체크한 글만 홈페이지에 나감** |

샘플 글도 하나 같이 만들어지니 바로 확인할 수 있습니다.
마지막에 출력되는 `NOTION_DATABASE_ID` 를 `.env.local` 에 추가하세요.

> "Could not find page" 오류 → 2)의 **연결**을 안 한 것입니다.

### ⚠️ 이미지 주의
**노션에 업로드한 이미지는 약 1시간 뒤 주소가 만료됩니다.**
커버와 본문 이미지는 **이미지 주소(URL)를 붙여넣어** 쓰세요.

## 4. 수강생이 고칠 곳은 `lib/site.js` 하나

이 파일만 본인 정보로 바꾸면 사이트 전체 + 검색/AI 정보가 같이 바뀝니다.

- `name` `tagline` `description` — 이름과 한 줄 소개
- `url` — 도메인 연결 후 실제 주소
- `business` — **⭐ 지역 업체 정보** (아래 5번 참고)
- `services` — 강의 분야 카드
- `cta` — 카카오톡 오픈채팅 링크

## 5. ⭐ LocalBusiness 스키마 (제미나이 스펙에 빠진 부분)

AI가 *"창원 마케팅 강사 누구 있어?"* 에 답하려면
**"이 사람이 창원의 마케팅 강사다"라는 구조화된 사실**이 사이트에 있어야 합니다.

`app/layout.js`에 이미 들어 있고, `lib/site.js`의 `business` 값을 채우면 됩니다.

```js
business: {
  city: "창원시",
  region: "경상남도",
  telephone: "010-...",
  areaServed: ["창원","김해","진주","양산","부산","경남 전 지역"],
  sameAs: ["https://blog.naver.com/...", "https://instagram.com/..."],
}
```

> 🚨 **구글 비즈니스 프로필에 등록한 것과 글자 하나까지 똑같이 적으세요.**
> AI는 프로필과 사이트를 **대조해서** 업체를 확정합니다. 다르면 대조가 안 됩니다.
> 주소 공개가 싫으면 `streetAddress`는 비우고 지역(city/region)과 `areaServed`만 채워도 됩니다.

## 7. Netlify 배포 — **완성한 뒤에 한 번만**

> ⚠️ **여기까지 오기 전에 로컬에서 사이트를 완성하세요.**
> 한 번 연결하면 GitHub에 올릴 때마다 자동으로 빌드되어 무료 시간이 깎입니다.


1. 코드를 **GitHub에 올린다** (비공개 저장소도 가능)
2. Netlify → **Add new site** → **Import an existing project** → GitHub 저장소 선택
3. 빌드 설정은 `netlify.toml`이 자동 처리 (건드릴 것 없음)
4. **Site configuration → Environment variables** 에 2개 추가
   - `NOTION_TOKEN`
   - `NOTION_DATABASE_ID`
5. **Deploy**

### 노션 글을 즉시 반영하고 싶다면
기본은 1시간마다 자동 갱신(ISR)입니다. 바로 반영하려면
**Site configuration → Build & deploy → Build hooks** 에서 훅을 만들고,
그 주소를 즐겨찾기 해두었다가 글 쓴 뒤 한 번 열면 즉시 재배포됩니다.

---

### 배포 후 — 빌드 시간 아끼는 법

| 상황 | 하지 말 것 | 대신 |
|---|---|---|
| 디자인 수정 | 고칠 때마다 push | **로컬에서 다 고치고** 모아서 한 번 push |
| 오타 하나 | 바로 push | 다른 수정과 **묶어서** push |
| 노션 글 추가 | 재배포 | **아무것도 안 해도 1시간 뒤 자동 반영** (ISR) |
| 글을 지금 당장 반영 | 매번 재배포 | 급할 때만 Build hook 1회 |

**노션 글은 재배포가 필요 없습니다.** 이 템플릿은 1시간마다 알아서 새 글을 가져옵니다.
빌드가 필요한 건 **코드나 디자인을 바꿨을 때뿐**입니다.

무료 플랜은 월 300분입니다. 이 사이트 한 번 빌드에 1~2분이니
**모아서 올리면 충분히 여유롭습니다.**

## 8. 도메인 연결 (⭐ 검색 등록보다 먼저)

**반드시 도메인을 먼저 연결한 뒤에 검색엔진에 등록하세요.**

`xxx.netlify.app`으로 6개월 쌓아놓고 나중에 도메인을 사면,
검색엔진 입장에선 **완전히 새 사이트**라 그동안 쌓은 게 리셋됩니다.

1. 도메인 구매 (가비아·후이즈 등, `.com`/`.kr` 연 2만원 안팎)
2. Netlify → **Domain management → Add a domain**
3. 안내대로 네임서버 또는 DNS 설정
4. **⏳ 반영에 몇 시간~하루 걸립니다.** 안 된다고 계속 만지지 마세요
5. 연결되면 `lib/site.js`의 `url`을 실제 주소로 바꾸고 재배포

## 9. 검색 · AI 노출 (사이트 완성 후)

**이 단계를 건너뛰면 사이트를 아무리 잘 만들어도 아무도 못 찾습니다.**

### 필수 4가지 (우선순위 순)

| 순위 | 할 일 | 왜 |
|---|---|---|
| **1** | **구글 비즈니스 프로필** 등록 | 제미나이가 구글 기반. 이게 없으면 AI 추천의 시작점이 없다 |
| **2** | **네이버 플레이스 + 네이버 블로그** | 한국 검색 1위는 여전히 네이버(38.8%) |
| **3** | **구글 서치 콘솔** 등록 + 사이트맵 제출 | `https://내도메인/sitemap.xml` |
| **4** | **네이버 서치어드바이저** 등록 + 사이트맵 제출 | |

### 그다음에 효과 있는 것
- 수강생·고객 **후기를 외부에** 남기기 (구글 리뷰, 네이버 플레이스 리뷰) — 인용 표면의 77%가 사이트 밖
- 강의한 **기관 페이지에 이름이 남게** 하기
- 블로그 글에 **지역명 + 분야**를 자연스럽게 (예: "창원 소상공인 블로그 강의")

### 기대치
- 색인까지 **2~4주**
- AI 추천은 **더 오래 걸리고, 사이트만으로는 안 된다**
- ChatGPT가 실제로 추천한 지역 업체는 분석 대상의 **1.2%**뿐 — 조급해하지 말 것

## 10. 자주 걸리는 함정 정리

| 증상 | 원인 / 해결 |
|---|---|
| 글이 안 보임 | 노션 DB에 **통합 연결** 안 함 / **발행** 체크 안 함 |
| 이미지가 나중에 깨짐 | 노션에 **업로드**한 이미지 (1시간 만료) → **이미지 주소 붙여넣기**로 |
| 속성 이름 오류 | `제목/슬러그/요약/카테고리/발행일/발행` 정확히 |
| 한글이 단어 중간에서 잘림 | `body { word-break: keep-all }` — 이미 CSS에 포함됨 |
| 배포는 됐는데 글이 안 바뀜 | ISR 1시간 대기 중 → Build hook으로 즉시 재배포 |
| 도메인이 안 붙음 | DNS 반영 대기 (최대 하루) |

## 12. 검증 완료 기록

이 템플릿은 배포 전 실제로 확인했습니다.

```
✓ Compiled successfully
Route (app)       Revalidate  Expire
┌ ○ /                     1h      1y     ← 홈 (ISR)
├ ○ /blog                 1h      1y     ← 목록 (ISR)
├ ● /blog/[slug]                         ← 상세 (SSG, 글마다 미리 생성)
├ ○ /robots.txt                          ← 자동 생성
└ ○ /sitemap.xml                         ← 자동 생성
```

`●` = 빌드 시점에 **완성된 HTML**로 만들어짐 → AI 크롤러가 JS 없이 바로 읽음.
이게 이 구조를 쓰는 이유입니다.
